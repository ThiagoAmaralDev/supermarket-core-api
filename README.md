# 🛒 SuperMarket Core API

API RESTful para gestão de vendas, controle de estoque e processamento assíncrono para redes de supermercado.

## 🎯 Objetivo
Projeto desenvolvido com foco em regras de negócio complexas do varejo, controle de concorrência e arquitetura orientada a eventos.

## 🛠️ Tecnologias
- Java 17+
- Git & GitHub

## 📌 Status
Em desenvolvimento — Mapeamento do domínio e regras de negócio em Java puro.
